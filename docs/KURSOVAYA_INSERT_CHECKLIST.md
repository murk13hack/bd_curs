### Пошагово (Mermaid `.mmd`)

1. Открыть файл в редакторе, скопировать содержимое.  
2. Вставить на https://mermaid.live  
3. **Actions → Export PNG** (или SVG, если кафедра принимает).  
4. В Word: курсор на строку `[Вставить рисунок N]` → Вставка → Рисунок → под рисунком подпись: *«Рисунок N — …»* (текст подписи уже в MD под заглушкой).

### Пошагово (PlantUML `.puml`)

1. Скопировать файл целиком в https://www.plantuml.com/plantuml  
2. Скачать PNG.  
3. Вставить в Word как выше.

### Пошагово (BPMN `.bpmn`)

1. Camunda Modeler → Open → выбрать `.bpmn`.  
2. При необходимости подправить подписи на русском.  
3. File → Export as PNG/SVG.  
4. Вставить в Word.
